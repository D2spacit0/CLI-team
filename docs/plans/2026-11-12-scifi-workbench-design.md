# 科幻工作台视觉与布局改版

用户已授权改造界面、重构布局，并在完成后提交到现有 GitHub 仓库。本轮将上一轮业务升级与新界面一起交付，项目、独立验收、固定稿件和发布确认继续使用真实业务状态。

## 设计取舍

采用“轨道指挥舱”：以项目的责任交接为主线，把负责人通讯和整稿审阅安排在同一工作面上。相比密集霓虹 HUD，它能承载长篇中文；相比单纯换成深色的原三栏，它增加可定位的真实交接阶段和清晰的操作层级。界面服务于交代目标、追踪工作和审阅成果，不增加营销区或虚构运行指标。

```text
┌ 品牌 / 当前工作区 ─────────── 连接状态 / 活跃作业 / 调度控制 ┐
│功能坞│ 项目索引 │ 项目指挥条：派发 → 接纳 → 收件 → 验收     │
│      │ 搜索     ├─────────────────┬────────────────────────┤
│项目  │ 项目     │ 负责人通讯       │ 整稿审阅坞             │
│待发布│ 团队     │ 待处理 / 交接记录 │ 版本 / 正文 / 原始配图 │
│任务  │ 历史     │ 成员说明与程序证据│ 程序检查 / 独立审稿    │
│设置  │          │ 持久保存的输入框  │ 退回修改 / 最终批准    │
└──────┴──────────┴─────────────────┴────────────────────────┘
```

窄屏保留项目选择、搜索和会话/整稿切换，搜索命中会话时自动让目标可见。阶段数据来自当前工作项；空值、受阻、失败、发布未知单独呈现。

## 视觉约定

| 用途 | 色值 |
| --- | --- |
| 深空画布 | `#080F1B` |
| 主面板 | `#101E30` |
| 内嵌面板 | `#0C1727` |
| 正文 | `#E2EDF8` |
| 冰青操作色 | `#65E5EE` |
| 琥珀待处理色 | `#FFBE73` |

次要文字使用 `#8B9FB8`，成功与失败使用各自的语义色。显示字体使用 Bahnschrift 配合中文系统字体，正文使用 Microsoft YaHei UI / PingFang SC，编号与时间使用 Cascadia Code / Consolas。以精细框角和阶段线路作为识别元素，网格只出现在有限背景区域。避免扫屏动画、假装实时的数值与大面积发光；支持减少动效与清晰键盘焦点。

整稿文字保持可读，实际图片不施加滤镜。程序收件、成员审稿和平台证据各自陈述事实；状态颜色不构成额外验收，也不改变批准条件。

## 实施与验收

- 根任务负责全局 tokens、外壳、旧视图主题一致性和集成。
- 项目界面代理负责项目索引、指挥条、负责人通讯和响应布局。
- 整稿界面代理负责固定版本审阅与待发布队列。
- 发布代理核对 Git 目标、候选文件、桌面成品与运行依赖。
- 实际浏览器验证项目建立、草稿、上下文、搜索、历史版本、图片、退回、未知发布和窄屏；检查对比度、可访问焦点与溢出。
- 最终执行 `npm test`、`npm run check`、`npm run build`，重打桌面包并确认快捷方式、启动与退出。
- 使用现有认证正常提交与推送；排除本地工作目录、参考仓库、构建包和凭据路径，不做强制推送。
