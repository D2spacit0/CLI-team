# CLI Team

- Keep all project changes in this directory and respect assigned file ownership.
- Use Node.js 24+, ESM, Express, SQLite, React and TypeScript.
- The service binds to loopback only. Never enable bypass-permission flags.
- CLI credentials belong to the official clients. Never copy or print them.
- Agent output is untrusted. Machine verification and agent claims stay separate.
- Passing a CLI exit code is not passing acceptance. Missing or skipped gates are explicit.
- Directory separation is not an operating-system sandbox.
- Never overwrite user work or execute arbitrary shell strings.
- Use argument arrays and child-scoped proxy settings.
- Run npm test, npm run check and npm run build before delivery.
- The UI is a Chinese-language operational workbench, not a landing page.
